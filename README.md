# 🏏 Cricket Game in C...

## 📌 Overview:

This project is a simple cricket game developed using the C programming language. It simulates a basic cricket match where users can play by interacting through the console.

The game includes features like batting, score tracking, and match outcomes based on user inputs and randomization.

---

## 🎮 Features:

* Console-based cricket gameplay.
* User vs Computer simulation.
* Random score generation.
* Match result display (Win/Loss/Draw).
* Simple and easy-to-understand interface.

---

## 🛠️ Technologies Used

* **Programming Language:** C Only!
* **Compiler:** GCC / Turbo C / Any standard C compiler

## 🚀 How to Run

1. **Clone or Download the Repository**

   ```
   git clone <your-repo-link>
   ```

2. **Navigate to the Project Folder**

   ```
   cd Cricket-Game-In-C
   ```

3. **Compile the Code**

   ```
   gcc cricket.c -o cricket
   ```

4. **Run the Game**

   ```
   ./cricket
   ```

---

## 🎯 How to Play

* The game will prompt you for inputs (like runs or choices).
* You play against the computer.
* Scores are calculated based on your inputs and random values.
* The final result is displayed at the end of the match.
